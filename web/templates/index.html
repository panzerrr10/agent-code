🛡️ 执行策略（危险动作放行）

默认：允许装依赖（否则遇到 ModuleNotFoundError 就死）、 不允许联网、不允许推送。
⚠️ 因为装依赖默认开，沙箱容器默认是 bridge 网络 —— curl/git pull 仍在命令层被拦，但 run_python 里的 requests 能直接出网。

⚠️ 有开关被环境变量接管了，界面上改了也不生效。 想用界面控制，请去掉 AGENT_ALLOW_* 环境变量后重启。

打开后沙箱容器也会从 --network=none 切到 bridge，否则命令放行了容器里还是出不去。

安装会执行包自带的安装脚本（postinstall），这是它比「单纯下载」更危险的地方。

单独一项，因为它会把你的代码发到外部服务。

多 Agent 模式下，Reviewer 会自己读改动过的代码、并跑一次测试来核实结果。 关掉它 → 评审只做静态审查（结论里会注明「未运行测试」）。 等级 1（只读）下无论如何都不会跑。

🎯 默认与用途

知识库（向量检索）需要一家支持 embedding 的提供商； 不选则退到默认提供商。

🔒 密钥只保存在服务端（data/providers.json，权限 600）， 浏览器永远拿不到完整值，只显示掩码。
⚠️ Base URL 填什么，密钥就会被发到那个地址，请只填你信任的端点。

📋 项目约定（AGENTS.md）
